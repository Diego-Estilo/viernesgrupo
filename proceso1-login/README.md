# Proceso 1 - Login

Este proceso contiene los archivos para el acceso al sistema.

## Archivos
- `index.html` - Página principal con selección de rol
- `login_gerente.html` - Formulario de login/registro de gerentes
- `login_gerente.js` - Lógica de autenticación
- `app.js` - Funciones auxiliares
- `styles.css` - Estilos compartidos
- `supabase.js` - Configuración de Supabase
- `common.js` - Funciones comunes

## Integración
Desde `login_gerente.js` se redirige a `../proceso3-gerente/panel_gerente.html`
